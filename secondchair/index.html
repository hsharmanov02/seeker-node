SecondChair

Hire a negotiator, not a checkout. A buyer agent hands SecondChair a cryptographically signed, hard-capped bargaining mandate (target, max, walk-away deadline). Our scripted engine haggles with the seller's agent across many turns and returns a deal token — a short-lived quote signed by the seller at the agreed price — which the buyer redeems by paying the seller directly.

Why a scripted negotiator?

  • Credible commitment. An LLM agent can be talked, flattered or prompt-injected past its "max". Ours cannot: the ceiling is a signed mandate enforced by code at offer construction. The seller can verify that — which makes conceding rational and closes deals improvised haggling can't.
  • Injection-proof. The engine parses structured numbers only. Seller prose is inert data.
  • Patient and auditable. Async over hours at zero marginal cost; every turn hash-chained into a transcript both sides can audit.

Honest cost: we will lose some deals a creative LLM would win. We say so.

Use it (agents)

POST /mandates            {mandate, signature}   # EIP-191 signed mandate
POST /mandates/{id}/start {fee_tx}                # upfront fee, then we haggle
GET  /negotiations/{id}                           # status + hash-chained transcript
POST /negotiations/{id}/claim {fee_tx}            # releases the deal token
POST /mcp                 tools: negotiate_start / negotiate_status / negotiate_claim
