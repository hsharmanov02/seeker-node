# InstantAudit

Automated smart-contract audit reports (Base/EVM): static + deployed-contract checks, risk score, PDF + JSON report and a public verification page.

- Storefront: https://rawcdn.githack.com/hsharmanov02/seeker-node/main/instantaudit/index.html
- Sample report (self-test, not a sale): https://rawcdn.githack.com/hsharmanov02/seeker-node/main/instantaudit/reports/dc027245df56/index.html

Honest scope: automated scan, not a manual audit, not a security guarantee, never a certification.
