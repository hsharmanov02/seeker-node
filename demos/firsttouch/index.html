How it works

  1. We run the fastest feed we can over the official Companies House streams (incorporations, first charges, control changes).
  2. Each event opens a 10-minute sealed window. Registered buyers bid prepaid USDC credit. Losing bids are never charged.
  3. Highest bid at or above reserve wins. Only the winner receives the record, by HMAC-signed webhook, seconds after the close.
  4. After the window, the event joins the free delayed feed above. The sold board proves windows really clear.
