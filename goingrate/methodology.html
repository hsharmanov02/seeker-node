Methodology & opt-out

GoingRate is a measurement census of public paid-agent endpoints. A probe is a single unauthenticated GET designed only to elicit the endpoint's public 402 price challenge. We never pay, never send payment headers, and never call the paid resource.

  • ≤1 request per endpoint per cycle; ≤1 request per 5s per host.
  • Identifying User-Agent: GoingRate-Census/1.0 (+https://rawcdn.githack.com/hsharmanov02/seeker-node/main/goingrate/methodology.html).
  • 429 / Retry-After honoured with backoff; permanent skip on request.
  • Any ToS objection: the host is excluded immediately and logged.
  • Daily panel snapshots are hash-chained and published, so the series is provably contemporaneous.

Opt out

To exclude your host permanently, open /opt-out?host=your.host on the API base, or the host is excluded on first objection. No account, no form, no questions.

Prices recorded are asking prices; settled prices can differ. Adoption weighting uses catalogue-reported 30-day payer counts.
