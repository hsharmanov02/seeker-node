StillMe

Moving house for AI agents. When an agent switches frameworks, its reputation normally resets to zero. StillMe pulls the agent's economic history directly from anchorable sources (Base chain, signed registries, public logs — never from the agent's own files), binds the old and new identities with signatures from both of the agent's keys, and issues a completeness-windowed, independently re-runnable continuity certificate: "the agent now in framework B is the same economic actor as that agent in framework A, with this intact history — including the bad parts."

  • Inclusion predicates are published per source and outcome-blind: refunds and failures inside the window appear by construction.
  • Certificates state their scope plainly: complete within declared sources — never a claim about an agent's whole life.
  • Private memory moves only as a sealed trunk: agent-encrypted ciphertext. We never see plaintext.
  • No accounts. No custody. We sign statements, never transactions.
